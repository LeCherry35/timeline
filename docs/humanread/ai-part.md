AI (агент или LLM) помогает пользователю управлять списком событий. По запросам пользователя AI может (с помощью инструментов):
- понять что найти в вики и выполнить поиск
- добавлять найденые события в список
- удалять события из списка

Попробуем сначала использовать готовый харнесс Claude Code и OpenCode.
В будущем можно будет перейти на собственный харнесс или упростить до вызовов модели.
