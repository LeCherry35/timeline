Главная идея проэкта - наглядно визуализировать исторические данные, так, чтобы было удобно прослеживать взаимосвязи различных событий. 

## Набор событий
Есть набор событий (в некоей переменной) изначально пустой. Есть интерфейс чата. В чате пользователь обьясняет, какие именно события его интересуют - тоесть манипулирует этим списком. У каждого события, помимо других аттрибутов есть аттрибут "важность", который нужен для правильного отображения визуализации при масштабировании

## Визуализация 
Визуализация списка - временная прямая, где точками отмечены события. Чем важнее событие, тем крупнее точка. При наведении на точку отображается больше информации о событии, при нажатии на точку открывается соответствующая статья в википедии.

## Гео-визуализация (в планах на будущее)
В будущем планируется расширение интерфейса визуализации - отображение событий на карте/глобусе. На временной прямой есть ползунок, он токазывает какой момент истории отображается на карте/глобусе. Кнопка "play" запускает ползунок и смену событий можно увидеть в динамике.
